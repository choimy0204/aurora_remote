## ⬇ 받기

최신 실행 파일은 [`dist/latest`](dist/latest) 에 있습니다.

| 파일 | 설치 위치 |
|---|---|
| [AuroraServer.exe](dist/latest/AuroraServer.exe) | 관리하는 PC (1대) |
| [AuroraClient.exe](dist/latest/AuroraClient.exe) | 각 설비 PC |
| [version.json](dist/latest/version.json) | 현재 버전 정보 |

이전 버전은 [`dist/old`](dist/old) 에 버전별로 보관합니다.

## 주요 기능

- **서버 뷰** — 설비 PC 상태(연결 · Aurora 실행 · 응답 · 핑)를 한눈에 보고, 공정 단위로 Aurora 실행/종료
- **배포 뷰 / 단일 배포 뷰** — 새 버전 폴더 통째로, 또는 설정 파일 몇 개만 여러 PC에 한 번에 배포
- **반입/반출** — 가까운 장비 하나를 중계로, 공정망의 다른 장비와 파일 주고받기
- **원격** — 원격 창 하나로 공정망 장비 화면 보기 · 조작 (이중 · 삼중 원격 불필요)
- **자동 업데이트** — Update 폴더에 새 버전을 넣으면 서버 · 클라이언트가 스스로 교체
